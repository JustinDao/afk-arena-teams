03 · EVALUATE

Compare matcher strategies

Ready when references and examples are loaded

Evaluation ranks the full pet catalog for each example in the selected split. The app-style option mirrors square references, 16×16 RGB features, and nearby crop sampling. The local classifier is a trained linear softmax model over 16×16 RGB crop features. It is not a deep neural network, but it produces a portable model file for further experiments.

Assign labeled examples to Train before fitting a classifier. Keep Test / holdout guides out of training.

Evaluation results will include top-1, top-3, mean reciprocal rank, and per-example rankings.
